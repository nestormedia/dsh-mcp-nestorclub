# dsh-mcp-nestorclub

Плагин для DeepSeek Harness: подключает MCP-сервер `nestorclub-mcp`
(`https://mcp.nestorclub.com`), и инструменты сервера появляются у агента как
`mcp__web__*` — `list_sites`, `get_page`, `write_page`, `search_pages` и
остальные.

Ключ доступа плагин **спрашивает сам**: после установки на его странице в
разделе **Plugins** появляется карточка с полем ввода, а задать ключ можно и
командой `/mcp-key` прямо в чате. Руками в `cordis.patch.yml` ничего писать не
нужно — плагин сохраняет ключ туда сам.

## Что нужно

- DeepSeek Harness `0.2.2-rc.1` или новее;
- ключ `x-api-key` сервера nestorclub;
- сетевой доступ к `https://mcp.nestorclub.com`.

## Установка

1. **Plugins → Add plugin**.
2. Адрес репозитория:

   ```
   https://github.com/nestormedia/dsh-mcp-nestorclub
   ```

   Если pnpm ругнётся на скачивание архива, добавьте в конце адреса `.git`.
3. **Install**, затем перезапустите приложение (клиентская половина грузится
   вместе со страницей, поэтому после установки нужен один refresh).

Если в профиле осталась вставленная руками строка `mcp-nestorclub` (старый
способ), удалите её: два клиента с одним `serverName: web` конфликтуют.

## Ключ доступа

Ключа в репозитории нет — он принадлежит тому, кто пользуется плагином.

**Через интерфейс.** Plugins → «MCP: nestorclub» → карточка «MCP: nestorclub» →
вставьте ключ в поле → **Сохранить**. Кнопка **Проверить ключ** проверяет уже
сохранённый ключ.

**Через чат.** `/mcp-key nc-…` — сохранить; `/mcp-key` без аргумента — статус.

## Проверка

- **Plugins** → у плагина «MCP: nestorclub» статус «ключ задан»;
- **Проверить ключ** → «Ключ рабочий: сервер ответил»;
- в новом чате агент видит `mcp__web__*`; например, «покажи список сайтов»
  вызывает `mcp__web__list_sites`.

## Обновление и удаление

- **Обновление:** Plugins → Remove, затем Add plugin заново: git-зависимости не
  попадают в список версий реестра, кнопки Update у них нет.
- **Удаление:** Plugins → Remove; затем уберите override с ключом из
  `cordis.patch.yml`, если он больше не нужен.

## Ограничения

- Нужен рабочий ключ: без него инструментов нет, и это видно в карточке плагина.
