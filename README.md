# dsh-mcp-nestorclub

Плагин для DeepSeek Harness: подключает MCP-сервер `nestorclub-mcp`
(`https://mcp.nestorclub.com`), и инструменты сервера появляются у агента как
`mcp__web__*` — `list_sites`, `get_page`, `write_page`, `search_pages` и
остальные.

Ключ доступа плагин **спрашивает сам**: после установки на его странице в
разделе **Plugins** появляется карточка с полем ввода, а задать ключ можно и
командой `/mcp-key` прямо в чате. Руками в `cordis.patch.yml` ничего писать не
нужно — плагин сохраняет ключ туда сам.

## Что нужно

- DeepSeek Harness `0.2.2-rc.1` или новее;
- ключ `x-api-key` сервера nestorclub;
- сетевой доступ к `https://mcp.nestorclub.com`.

## Установка

1. **Plugins → Add plugin**.
2. Адрес архива:

   ```
   https://github.com/nestormedia/dsh-mcp-nestorclub/archive/refs/heads/main.tar.gz
   ```

   Это адрес архива, а не репозитория: pnpm не вызывает git, поэтому установка идёт и на машине без git. Адрес ведёт на текущую ветку `main`; чтобы зафиксировать версию, замените `refs/heads/main` на sha коммита.

   > **Адрес репозитория не подойдёт.** Строка вида
   > `https://github.com/nestormedia/dsh-mcp-nestorclub` (без `/archive/...`) или
   > короткая запись `nestormedia/dsh-mcp-nestorclub` — это git-спецификация: и
   > DeepSeek Harness, и pnpm запускают для неё `git ls-remote`, и без git
   > установка падает с `[ERR_PNPM_GIT_RESOLVE_FAILED] … 'git' is not
   > recognized`. GitHub тут ничего не меняет — дело в форме адреса, а не в
   > хостинге. Вставляйте только адрес архива, он кончается на `.tar.gz`.

3. **Install**, затем перезапустите приложение (клиентская половина грузится
   вместе со страницей, поэтому после установки нужен один refresh).

Если в профиле осталась вставленная руками строка `mcp-nestorclub` (старый
способ), удалите её: два клиента с одним `serverName: web` конфликтуют.

### Если установка пишет про git

Значит в поле адреса оказалась строка не того вида. Признак:

```
[ERR_PNPM_GIT_RESOLVE_FAILED] Failed to resolve git dependency "https://github.com/nestormedia/dsh-mcp-nestorclub":
git ls-remote failed: 'git' is not recognized as an internal or external command
```

Замените её на архивную и повторите установку — git для неё не вызывается вообще:

```
https://github.com/nestormedia/dsh-mcp-nestorclub/archive/refs/heads/main.tar.gz
```

Проверено на машине, где `PATH` содержит только `C:\Windows\System32` (git
отсутствует): архив ставится, адрес репозитория — нет.

### Если пишет «This package is already installed»

Плагин уже стоит: в профиле сохранена зависимость ровно с этим адресом, поэтому DSH
отказывает ещё до запуска pnpm — сеть и git тут ни при чём. Переустановить (например,
чтобы подхватить свежий `main`) можно двумя способами.

**Через Uninstall.** **Plugins** → страница плагина → **Uninstall**, дождитесь, что он
исчез из списка, затем **Add plugin** → тот же адрес архива. Для плагинов из архива
это штатный путь обновления: секции **Versions** у них нет.

**Поверх, с фиксированным коммитом.** DSH сверяет адрес целиком, поэтому адрес с sha
не совпадёт с сохранённым и установка пойдёт:

```
https://github.com/nestormedia/dsh-mcp-nestorclub/archive/<sha>.tar.gz
```

Так в профиль запишется уже этот адрес, и версия будет закреплена.

## Ключ доступа

Ключа в репозитории нет — он принадлежит тому, кто пользуется плагином.

**Через интерфейс.** Plugins → «MCP: nestorclub» → карточка «MCP: nestorclub» →
вставьте ключ в поле → **Сохранить**. Кнопка **Проверить ключ** проверяет уже
сохранённый ключ.

**Через чат.** `/mcp-key nc-…` — сохранить; `/mcp-key` без аргумента — статус.

## Проверка

- **Plugins** → у плагина «MCP: nestorclub» статус «ключ задан»;
- **Проверить ключ** → «Ключ рабочий: сервер ответил»;
- в новом чате агент видит `mcp__web__*`; например, «покажи список сайтов»
  вызывает `mcp__web__list_sites`.

## Обновление и удаление

- **Обновление:** Plugins → Remove, затем Add plugin заново: git-зависимости не
  попадают в список версий реестра, кнопки Update у них нет.
- **Удаление:** Plugins → Remove; затем уберите override с ключом из
  `cordis.patch.yml`, если он больше не нужен.

## Ограничения

- Нужен рабочий ключ: без него инструментов нет, и это видно в карточке плагина.
